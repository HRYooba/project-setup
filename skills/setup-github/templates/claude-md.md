## 開発ワークフロー

- **ブランチ**: 実装前に必ずデフォルトブランチから作業ブランチを切る。デフォルトブランチへの直接コミット・直接 push は禁止。変更は必ず作業ブランチ経由の PR で入れる
- **レビュー**: スクリプト等のコード変更を含む PR は、作成前に**ブランチ全体の差分**に対して `/code-review` を 1 回実行し、指摘を反映してから PR を作る（`.claude/` `.github/` `.githooks/` のみの変更は対象外）
- **セキュリティレビュー**: 認証・トークン・暗号・ネイティブ呼び出し（P/Invoke / FFI）・外部通信のいずれかを新規追加または変更した差分があるときは、PR 作成前に `/security-review` を 1 回実行する
